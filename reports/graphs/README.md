# Report graphs

Generated by `make plots` (`scripts/plot_report.py`) from `reports/benchmark.csv`, `gmu_published.csv`,
`profile.csv`, `synth_runs.csv`, `nks_study.csv`, the sweep and two profile VCDs. All numbers are on
xc7a100tftg256-2L (Vivado 2026.1, out of context, LWC wrapper included), the part GMU used.

| Figure | Shows | Use it to argue |
|---|---|---|

## Sources
- GMU values: Mohajerani et al., *SCA Evaluation and Benchmarking of Finalists in the NIST Lightweight
  Cryptography Standardization Process*, ePrint 2023/484 (`docs/SCA-Benchmarking.pdf`), Tables 12 and 14,
  unprotected implementations. `reports/gmu_published.csv` is parsed from the PDF text, not retyped.
  Elephant_GMU is GMU's own Elephant (see `rtl/core_v2_r1/REFERENCE.md` for how it compares with ours).
- Cycle-accurate numbers come from Questa runs of the LWC testbench (`make cycles`, `make profile`).

## Regenerating
- matplotlib is not in the system Python. Install it somewhere and point `PYTHONPATH` at it, e.g.
  `python3 -m pip install --target /tmp/pylib matplotlib`, then `PYTHONPATH=/tmp/pylib make plots`.
- Figure 13 needs the optBCDEFGH profile VCDs with the issue signals added. Make the do-file with
  `python3 scripts/profile.py do --core v2_r4_optBCDEFGH --out build/prof/calls.do`, then add these lines
  before `run -all`:
  ```
  vcd add /LWC_TB/uut/Inst_Cipher/b_v
  vcd add /LWC_TB/uut/Inst_Cipher/b_p
  vcd add /LWC_TB/uut/Inst_Cipher/b_kind
  ```
  Then run, for WL in short and long:
  `make sim CORE=v2_r4_optBCDEFGH SET=prof_$WL SIM=questa VSIM_FLAGS=-voptargs=+acc VSIM_DO="do $PWD/build/prof/calls.do"`.
  Without them the figure is skipped.
- `reports/nks_study.csv` holds hand-measured points (NKS edited, `make cycles` rerun); see
  `rtl/core_v2_r4_optBCDEFG/OPT_BCDEFG.md` and `rtl/core_v2_r2_optBCDEFGH/OPT_BCDEFGH_R2.md`.
